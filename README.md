# GameReady

Windows 游戏配置便携工具，支持 LOL 配置守护、Steam 设置与账号管理，以及 NAS 账号备份。单 exe，无需安装。

## 下载与使用

1. 从 [Releases](https://github.com/BigdataZjk/GameReady/releases/latest) 下载 exe，或解压 zip 后运行；缺少 WebView2 时按提示安装。
2. 在路径设置中填写 LOL 或 Steam 安装目录，可只配置一个。
3. 按需使用以下功能，支持托盘运行和开机自启。

| 功能 | 用途 |
| --- | --- |
| LOL 配置守护 | 开启后持续应用内置游戏配置 |
| Steam 设置 | 合并全局与账号设置，默认打开库、弹出通知设为从不、关闭游戏更新及新品推广通知；开启叠加界面及其缩放，关闭浏览器选项卡恢复；操作时会退出并重启 Steam |
| Steam 账号 | 切换登录、新增账号、删除本机账号数据；历史账号在启动前应用设置，避免二次启动；首次新账号确认后应用设置并恢复登录 |
| 操作日志 | 查看操作结果和失败原因 |

登录进度会显示退出、配置、启动与等待确认的实际阶段。验证码或手机确认在 Steam 中完成；等待期间可重新选择账号，旧任务自动取消。首次新账号登录确认后会自动退出、应用配置并恢复登录；账号尚未写入 Steam 登录历史时，也能通过活动会话识别并显示。

Steam 历史账号按最近登录时间从新到旧显示。界面禁用默认右键菜单，仅账号行右键提供「复制账号」「复制密码」；复制密码使用本机保存的密码，缺失时会提示补充。点击「删除」直接清理所选本机账号，无确认弹窗。

登录按钮前的「识别」会检查剪贴板中的单行账号密码，支持重复符号、空格分隔及「账号：… 密码：…」等格式；可识别时启用，否则灰显。点击仅填入账号和明文密码，登录需另点「登录」。

## NAS 账号备份

在 Steam 页打开「账号备份」，填写服务器、端口、用户名、密码和远程文件绝对路径，例如 `/GameReady/accounts.txt`。端口默认 `2022`，请按 NAS 实际设置修改；SFTP 用户需有目标目录的读写、创建、删除及替换文件权限。点击「测试连接」通过后保存配置。

| 操作 | 行为 |
| --- | --- |
| 补充密码 | 展开明文输入框，确认后仅保存密码，立即变为「同步」按钮 |
| 同步 | 直接上传该账号已保存的密码，无需先登录 Steam |
| 全部同步 | 上传所有有密码且未同步的账号，缺密码的账号留待补充 |
| 自动备份 | 默认关闭；开启后，普通登录或新增账号确认登录成功时自动同步 |

待同步列表只显示未同步账号，「待补充密码」「待验证」以标签显示；补充密码不会启动 Steam。同步结果显示在弹窗底部，自动同步也会主动提示；登录完成提示同时显示该账号的 NAS 备份状态。

手动同步不受自动备份开关限制。远程文件为 UTF-8 文本，每行 `账号----密码`；新账号插入第一行，已有账号更新密码并保留原位置，不排序，保留远程其他账号。批量新增逐个置顶，相同密码已同步后不重复上传。失败时保留待同步记录，修正并保存配置或重新测试连接通过后继续重试。

## 数据与升级

- 设置、账号和日志均保存在 exe 同级 `Data` 目录。**所有密码输入框显示明文，Steam 和 NAS 密码也按明文保存在本地。**
- 升级前退出程序（包括托盘），替换 exe 并保留原 `Data` 目录。
- 公开发行 zip 仅含 `gameready.exe` 和本说明；分享时不要附带自己的 `Data`。

## 从源码构建

需要 Rust stable、MSVC C++ 构建工具和 Windows SDK。前端为静态 HTML，无需 Node 构建。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

生成根目录的 `gameready.exe`，并在 `release` 目录生成已清除编译机路径信息的 exe 和 zip。每次打包后先关闭正在运行的 GameReady，再替换桌面的 `GameReady.exe`，保留旁边的 `Data`。加 `-Clean` 可在构建后清理缓存。

`src` 放程序和测试，`assets` 放界面、图标及合并后的内置模板；`Data` 仍只在运行时生成。
