# GameReady

Windows 游戏配置便携工具，支持 LOL 配置守护、Steam 设置与账号管理，以及 NAS 账号备份。单 exe，无需安装。

## 下载与使用

1. 从 [Releases](https://github.com/BigdataZjk/GameReady/releases/latest) 下载 exe，或解压 zip 后运行；缺少 WebView2 时按提示安装。
2. 在路径设置中填写 LOL 或 Steam 安装目录，可只配置一个。
3. 按需使用以下功能，支持托盘运行和开机自启。

| 功能 | 用途 |
| --- | --- |
| LOL 配置守护 | 开启后持续应用内置游戏配置 |
| Steam 设置 | 合并快捷键、覆盖层、通知等设置，操作时会退出并重启 Steam |
| Steam 账号 | 切换登录、新增账号、删除本机账号数据；新增账号登录成功后自动应用设置 |
| 操作日志 | 查看操作结果和失败原因 |

## NAS 账号备份

在 Steam 页打开「账号备份」，填写服务器、端口、用户名、密码和远程文件绝对路径，例如 `/GameReady/accounts.txt`。端口默认 `2022`，请按 NAS 实际设置修改；SFTP 用户需有目标目录的读写、创建、删除及替换文件权限。点击「测试连接」通过后保存配置。

| 操作 | 行为 |
| --- | --- |
| 补充密码 | 展开明文输入框，确认后仅保存密码，立即变为「同步」按钮 |
| 同步 | 直接上传该账号已保存的密码，无需先登录 Steam |
| 全部同步 | 上传所有有密码且未同步的账号，缺密码的账号留待补充 |
| 自动备份 | 默认关闭；开启后，普通登录或新增账号确认登录成功时自动同步 |

「待补充密码」「待验证」以标签显示；补充密码不会启动 Steam。同步成功后账号立即移出待同步列表，单账号和全部同步的结果固定显示在弹窗底部。

手动同步不受自动备份开关限制。远程文件为 UTF-8 文本，每行 `账号----密码`；同账号合并并更新密码，相同密码已同步后不重复上传。失败时保留待同步记录，修正连接配置后可重试。

## 数据与升级

- 设置、账号和日志均保存在 exe 同级 `Data` 目录。**所有密码输入框显示明文，Steam 和 NAS 密码也按明文保存在本地。**
- 升级前退出程序（包括托盘），替换 exe 并保留原 `Data` 目录。
- 公开发行 zip 仅含 `gameready.exe` 和本说明；分享时不要附带自己的 `Data`。

## 从源码构建

需要 Rust stable、MSVC C++ 构建工具和 Windows SDK。前端为静态 HTML，无需 Node 构建。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

生成根目录的 `gameready.exe`，并在 `release` 目录生成已清除编译机路径信息的 exe 和 zip。加 `-Clean` 可在构建后清理缓存。

`src` 放程序和测试，`assets` 放界面、图标及合并后的内置模板；`Data` 仍只在运行时生成。
